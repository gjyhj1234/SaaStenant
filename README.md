# SaaStenant

租户系统。

## 数据库字典

当前仓库交付物为 **AI 编程优先的数据库字典文档**，不是数据库建表 SQL。

- `db/database_dictionary.md`

该文档用于：

- 让 AI 根据完整的表、字段、约束、关系和业务说明生成实体类
- 为后续程序运行时维护数据库结构提供统一的数据模型依据
- 帮助后续生成枚举、值对象、DTO 和 ORM 映射配置

文档内容覆盖：

- 平台管理体系
- 租户生命周期体系
- 租户信息体系
- 租户资源管理
- 租户配置中心
- SaaS 套餐系统
- 订阅系统
- 计费与账单系统
- API 与集成平台
- 平台运营体系
- 日志与审计
- 通知系统
- 文件与存储
- 技术基础设施
